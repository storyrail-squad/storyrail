# [Story] Loan history for a book

> Practice story **E1** for StoryRail exams. It is never in the backlog and never merged: every exam builds it again
> from the same frozen code (see `evals/evals.json`). Its hidden tests live in `evals/hidden/E1/` and agents never see them.

## Story

As a **librarian**, I want to **see when a book was borrowed and returned** so that **I can answer "who had it last
and since when" without a paper log**.

## Acceptance criteria

**Backend**
- BE-AC1: `GET /api/books/{id}/loans` returns the book's loans, newest first, as a page:
  `{ "items": [ { "borrowedAt": <date-time>, "returnedAt": <date-time or null> } ], "page", "size", "totalItems", "totalPages" }`.
  Query parameters `page` (default 0, ≥ 0) and `size` (default 20, 1–100), with the same `400` validation problem as the book list.
- BE-AC2: Marking an available book as on loan (`PATCH /api/books/{id}/availability` with `{"available": false}`) starts a
  loan (`borrowedAt` = now, `returnedAt` = null). Marking it available again ends that loan (`returnedAt` = now).
  Sending the value the book already has changes nothing.
- BE-AC3: An unknown book id returns `404` with the problem title `Book not found`. A book that was never borrowed
  returns `200` with an empty `items` list.
- BE-AC4: Deleting a book also deletes its loans.

**Frontend**
- FE-AC1: Each book in the catalog has a **Loan history** button (accessible name `Show loan history of <title>`). It
  opens a dialog named `Loan history of <title>` with one list item per loan, newest first: the borrowed date and either
  the returned date or **Not returned yet**.
- FE-AC2: A book without loans shows **Never borrowed** in the dialog.
- FE-AC3: If the history can't be loaded, the dialog shows **Couldn't load the loan history** with a **Try again** button.
- FE-AC4: The dialog closes with its **Close** button and with Escape; focus goes back to the button that opened it.

## Lanes

Frontend + backend (with API tests).

## Answers the squad already has

Questions a functional analyst would normally answer during refinement. In an exam nobody is asked, so they are written
down here; asking the user anyway counts as a human intervention.

- Loans from before this story are not known: books on loan in the seed data show **Never borrowed** until they are returned and borrowed again.
- Dates are shown in the browser's locale, date and time to the minute.
- No paging controls in the dialog: it shows the first 20 loans.
- The contract is changed in `docs/api/openapi.yaml` of the backend first, as usual.
