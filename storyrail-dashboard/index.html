  1. Fixed practice storiesKept apart from the backlog. Always the same, always built from the same frozen code.
  2. Hidden testsAn answer key per story that the agents never see, so they can't grade themselves.
  3. Several runs eachThe full squad runs every story 3 times. Nothing is pushed, merged or deployed.
