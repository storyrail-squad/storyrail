  2. Hidden testsAn answer key per story that the agents never see, so they can't grade themselves.
  3. Three runs eachThe full squad runs every story 3 times. Nothing is merged or deployed.
  4. CompareThe first exam is checked against your targets. Every later exam is compared with the one before, so a drop shows straight away.
